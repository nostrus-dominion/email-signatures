03 / SIGN, SEALED, SENT

Put it to work

Click Copy signature, then paste into your email client's signature editor. Save it and send yourself a test email.

Gmail

Settings → See all settings → General → Signature. Create a signature, paste it, choose your defaults, then Save Changes.

Google's signature guide ↗

Outlook

New Outlook and Outlook on the web: Settings → Accounts → Signatures.

Classic Outlook: File → Options → Mail → Signatures. Create a signature, paste it, and choose your defaults.

Microsoft's signature guide ↗

Other clients

Use the formatted copy in a rich-text signature editor. If your client accepts an HTML file, download HTML.

For a text-only editor, use the Plain text tab or Download text. Formatting and image support vary by client.

Hosting Logos

Download the prepared PNG, add it to your repository's assets/ folder, and publish the site. Use the direct image address:

https://USERNAME.github.io/REPOSITORY/assets/logo.png

Keep that address available so existing signatures can load the logo. Some recipients block remote images until they choose to display them.
